# BTCUSD Sniper
Single-file site (index.html). Upload index.html (and .nojekyll) to a GitHub repo root, then Settings > Pages > Deploy from a branch > main > / (root).
Uses Binance (M5, M1, 15m, book ticker) and Twelve Data (M15 and price cross-check, key entered on the splash screen).
Paper analysis only. No orders are placed. Signals have no proven edge.
